# 🧬 РУКОВОДСТВО ПО ИСПОЛЬЗОВАНИЮ ПАКЕТА АКТИВОВ HERASHIELD
**Папка назначения:** `HeraShield_Core_Package`
**Описание:** Данный каталог содержит все актуальные научно-практические материалы, расчетные модели молекулярной динамики, симуляции цифрового двойника и технологические карты для проекта борьбы с борщевиком Сосновского (*Heracleum sosnowskyi*).

---

## 📁 СОСТАВ ПАКЕТА И ОПИСАНИЕ ФАЙЛОВ

### 1. Документация и рецептуры (Техкарты)
*   **`formulation_variant_B_nanodots.md`** — Технологическая карта формуляции Варианта B на базе углеродных наноточек N,S-CQD-bPEI (себестоимость сырья ~1598 руб/га). Содержит физико-химические параметры упаковки РНК.
*   **`formulation_variant_C_chitosan.md`** — Технологическая карта формуляции Варианта C на базе хитозанового наногеля CLNC (себестоимость сырья ~1404 руб/га). Содержит параметры стабильности при разных pH.
*   **`CQD_Synthesis_Protocol.md`** — Детальный пошаговый протокол бытового микроволнового синтеза азот-легированных углеродных наноточек (N-CQD) из лимонной кислоты и мочевины.
*   **`formulation_comparison_matrix.md`** — Сравнительная экономико-технологическая бизнес-матрица для выбора оптимальной формуляции (A, B, C, D или E).
*   **`final_digital_twin_summary.md`** — Краткая сводка базовых параметров цифрового двойника.
*   **`manufacturing_and_strategy_report.md`** — Детальный коммерческий отчет по производственным площадкам в РФ/Китай, толлинговым расчетам, оценке патента методом DCF и дорожной карте ФЗ-109.
*   **`dsrna_market_and_innovation_report.md`** — Анализ мировых цен на дсРНК (на 2026 год), инноваций в упаковке (лигнин, везикулы) и удешевленных "whole-cell" методов.
*   **`silfluo_la11_surfactant_integration.md`** — Технический меморандум по интеграции кремнийорганического суперсмачивателя Silfluo LA-11 (CAS 27306-78-1, Nanjing Silfluo New Material Co., Ltd.) в баковые смеси для снижения поверхностного натяжения до < 21.0 мН/м и экономии 20-30% дсРНК.
*   **`HeraShield_Master_Business_Plan.md`** — Единый консолидированный мастер-бизнес-план проекта (Executive Summary, анализ рынка TAM/SAM/SOM, GTM-стратегия, толлинговая модель, 5-летний P&L-прогноз, NPV/IRR и план снижения рисков).

### 2. Моделирование и расчетные скрипты
*   **`run_local_md.py`** — Нативный Python-симулятор Langevin-динамики комплекса PP2-A1 + RNA Loop-7 (Вариант A). Не требует сторонних библиотек (кроме biopython).
*   **`run_local_md_variant_B.py`** — OpenMM симулятор молекулярной динамики комплекса РНК с разветвленным полиэтиленимином (bPEI) на GPU (OpenCL/CUDA).
*   **`run_local_md_variant_C.py`** — OpenMM симулятор молекулярной динамики комплекса РНК с олигомером хитозана на GPU (OpenCL/CUDA).
*   **`run_all_digital_twin_simulations.py`** — Главный скрипт расчетов цифрового двойника (включает биоинформационный офф-таргет Apiaceae, Монте-Карло тканевых барьеров, ODE-решатель распада в среде, Leslie-модель популяции сорняка на 10 лет и COGS чувствительность).

### 3. Google Colab и облачные симуляции
*   **`HeraShield_Digital_Twin_Colab.ipynb`** — Интерактивный Jupyter-блокнот для Google Colab. Содержит все 5 моделей цифрового двойника с панелями управления (`ipywidgets`) и графиками. Специально оптимизирован для работы в Colab.
*   **`colab_agent_instructions.md`** — Системная инструкция для ИИ-агента, запускающего расчеты в среде Google Colab.

### 4. Результаты расчетов и сырые данные
*   **`digital_twin_simulations_report.md`** — Итоговый подробный научно-вычислительный отчет с графиками, цифрами и выводами.
*   **`digital_twin_results.json`** — Структурированные сырые данные расчетов цифрового двойника.
*   **`trajectory_variant_B.dcd`** / **`trajectory_variant_C.dcd`** — Бинарные файлы траекторий молекулярной динамики.
*   **`thermo_log_variant_B.csv`** / **`thermo_log_variant_C.csv`** — Пошаговые логи физических параметров (энергии, RMSD, температуры).

### 5. Лабораторная валидация (Мокрые тесты)
*   **`wet_lab_protocol.md`** — Детальный пошаговый лабораторный регламент для мокрых тестов (blank validation на листьях, отжиг РНК, ПЦР в реальном времени нокдауна гена CYP71AJ).

## 🚀 ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ

### Сценарий 1: Локальный запуск симуляций на ПК
Для запуска симуляций молекулярной динамики требуется видеокарта Nvidia (RTX 4060 или лучше) и установленный Python-пакет `openmm`.
1.  **Запуск симуляции РНК-bPEI (Вариант B):**
    ```bash
    uv run --with openmm python run_local_md_variant_B.py
    ```
2.  **Запуск симуляции РНК-Хитозан (Вариант C):**
    ```bash
    uv run --with openmm python run_local_md_variant_C.py
    ```
3.  **Запуск расчетов цифрового двойника (все 5 моделей):**
    ```bash
    python run_all_digital_twin_simulations.py
    ```

### Сценарий 2: Интерактивный запуск в Google Colab (Облако)
Используйте этот сценарий для презентаций или демонстрации результатов инвесторам без необходимости настройки GPU на локальном ПК:
1.  Перейдите на **[Google Colab](https://colab.research.google.com/)**.
2.  Загрузите файл `HeraShield_Digital_Twin_Colab.ipynb`.
3.  Нажмите **«Среда выполнения» -> «Выполнить все»** (`Ctrl + F9`).
4.  Используйте слайдеры для изменения цен на дсРНК, эффективности барьеров доставки или степени защиты от солнца, чтобы увидеть, как меняется рентабельность, выживаемость РНК и скорость искоренения борщевика.

### Сценарий 3: Передача ТЗ в лабораторию («Мокрые тесты»)
1.  Отправьте файл `wet_lab_protocol.md` вашим технологам или сторонней лаборатории (CRO).
2.  Этот файл содержит готовую инструкцию по смешиванию дсРНК с наноточками или хитозаном, контролю смываемости дождем, оценке расширения пор клеточной стенки листа с помощью лизоцима и измерению реального нокдауна гена *CYP71AJ* методом RT-qPCR.
